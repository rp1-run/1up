# README Icons

Icons in this directory are vendored for the repository README redesign.
The SVGs are normalized to a neutral README gray so they remain legible in
GitHub light and dark themes when embedded as image files.

## Sources

- `heroicons-solid/`: Heroicons solid 24px SVGs from `tailwindlabs/heroicons`.
- `lobehub/`: Static SVG brand icons from LobeHub's `@lobehub/icons` icon set.

## Current Set

Heroicons cover generic README concepts such as setup, search, tools, architecture,
local indexing, security, update, benchmarks, docs, and source builds.

LobeHub icons cover the agent/provider brands that appear in the README host
surface: Codex, Claude Code, Cursor, GitHub Copilot, MCP, OpenAI, and GitHub.
